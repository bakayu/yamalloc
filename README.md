## Project description

`yamalloc` is an attempt at developing a memory allocator that allows the programmer to:

1. Ask for memory from the allocator. (equal of `malloc`)
2. Allows the programmer to free prior allocated memory. (equal of `free`)
3. Allows the programmer to re-allocate prior allocated memory. (equal of `realloc`)

This project aims for correctness over efficiency.
